# Solution Overview

ScanAssist is a safety-first troubleshooting assistant designed for CT and MRI technologists.

The system allows users to:

- Search troubleshooting procedures
- Follow guided checklists
- View risk levels and severity
- Receive recommendations
- Generate engineer escalation reports
- Track troubleshooting analytics

The application uses a structured knowledge base of approved troubleshooting procedures and presents them through an easy-to-use Streamlit interface.

When an issue cannot be resolved, ScanAssist generates a professional engineer handover report containing machine details, completed checks, and escalation information.
