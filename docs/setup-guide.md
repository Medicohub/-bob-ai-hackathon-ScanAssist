# Setup Guide

## Requirements

- Python 3.10+
- pip

## Installation

Clone repository:

git clone <repository-url>

Open project:

cd ScanAssist

Install dependencies:

pip install -r src/requirements.txt

Run application:

streamlit run src/app.py

## Access

Open browser:

http://localhost:8501

## Features

- Dashboard
- Troubleshooting
- Reports
- Analytics
